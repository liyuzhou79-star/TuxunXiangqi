# 将！ v1.26.0 更新说明

这一版专攻局内质感：棋子从「每一帧现画」换成「预先做好的成品图」，棋盘补了光影细节，整盘棋看起来更像一套真的木棋。

## 改进

- **棋子换成预烘焙的成品图**：14 个棋子面（红黑双方各 7 种）全部提前做好——真实木纹（沿用棋盘同源的胡桃木实拍纹理，提亮成黄杨木色，每只棋子的纹理角度都不同）、棋子侧壁的厚度、刻字双环的凹槽光、书法字的浮雕压痕、边缘倒角的高光，一次全烘进图片。对局时直接贴图，运行时只再画一层实时投影（落子滑动时投影会跟着变），不再靠每帧的渐变色块拼棋子。
- **棋盘补光影**：楚河汉界一带加了极轻微的色差，两边疆域一眼可分；盘面内侧四边补了倒角光——上、左边是亮边，下、右边是暗边，盘面更像一块有厚度的真木板，而不是贴了一张图。
- 选中光圈、落子光晕、将军脉冲这些动态效果保留原来的实时绘制，和新棋子贴图对齐过，不会有「真棋子配塑料特效」的割裂感。

## 说明

- 全套棋子图片用 WebP 压缩，总共约 0.44 MB，安装包体积基本不变。
- 图片加载完成前会短暂用原来的画法顶一下（通常一瞬间），不会出现空盘。
- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
