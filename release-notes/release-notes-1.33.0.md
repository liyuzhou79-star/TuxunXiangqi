# 将！ v1.33.0 更新说明

这一版把三处「看不见的进度」补齐：复盘深算的结果不再关掉页面就消失，猜一选的开局题会写明出自哪条定式，战绩页能一眼看到最近一周的每日一题有没有跟上。

## 新功能

- **复盘深析结果存进棋谱**：以前在复盘页对某一步做的深度分析（引擎看约 2 秒的四候选）只在当页临时显示，退出就没了。现在深析一完成就存进这条棋谱：下次打开同一条棋谱，那一步的深析卡片直接还在，不用重算；通过复制、分享、文件导出的棋谱也会带上深析结果，导入到另一台设备后照样能看。整份数据备份同样会带上深析结果。
- **猜一选开局题标注定式线名**：「开局」题源的每道题现在会写明出自哪条定式——比如「顺炮 · 定式走了 5 手」，不再是匿名的开局局面。练猜一选的同时，能顺带把中炮、顺炮、仙人指路、飞相局、对兵局这些线的走法认熟。

## 优化

- **战绩页近 7 天每日一题点阵**：「训练进度」卡的每日一题一行下面多了一排小圆点，近 7 天哪天解了、哪天漏了，一眼看清；今天的圆点带一圈描边，不会认错日子。

## 说明

- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
