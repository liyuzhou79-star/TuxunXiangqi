# 将！ v1.16.0 更新说明

这一版把开局库和对局打通了：以前在开局库里只能看，现在看中哪条定式线，可以直接从那个局面接着往下下。

## 新功能

- **从开局库局面直接开局**：开局库浏览页的预览棋盘下面多了两个按钮——「从这个局面人机对弈」和「从这个局面人人对弈」。在库里选中任意一条线（比如中炮对顺炮走到的局面），点按钮就带着这个局面进对局，不用再去摆棋编辑器里手动摆一遍。
- **轮次如实带入**：选中局面该哪方走棋，对局里就由哪方先走，预览标题里也标明了（红方走棋／黑方走棋）。人机对弈时如果轮到引擎那方，它会先走第一步；中途退出，这局照样能从首页「继续对局」接着下，轮次不会丢。

## 优化

- **自定义局面开局的轮次处理统一**：对局页接受起始局面时不再写死红方先行，而是按局面自带的轮次走。摆棋编辑器原来的行为不变（仍是红方先行），开局库带入的黑方轮次局面是这次新补齐的。

## 说明

- 本版是正式签名版，可直接覆盖 1.15.0 及更早正式版升级，棋谱和设置都保留。
- 从开局库开的局，棋谱会按自定义局面正常保存，初始局面和轮次都记在谱里，复盘打开就是当时的局面。
