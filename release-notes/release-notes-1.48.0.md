# 将！ v1.48.0 更新说明

开局库从 60 个定式节点扩充到 66 个，四条主线继续往深里走，最深的线路已经能陪你走完前十手。

## 新增

- **顺炮线**：横车、炮八进二之后，红方进兵、平车的续招入库；再往深一层，黑方进卒之后红方的三种续招也补齐了。
- **中炮对屏风马线**：平车之后红方兵七进一的续招、黑方出车飞象的应法入库。
- **仙人指路转中炮线**：红方炮八进二之后，黑方平车、出车、进卒的应法入库。
- **飞相局线**：红方兵三进一之后，黑方双卒齐进、出车的应法入库。

新增节点全部经过本地校验程序逐手核对：每一步历史着法、每一条建议着法都合法，建议的中文记谱与记谱生成器逐字一致。
