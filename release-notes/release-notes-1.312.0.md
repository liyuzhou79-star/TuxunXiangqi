# 将！ v1.312.0 更新说明

功能打磨第八版：把「继续对局」快照的存盘挪离了界面线程。

## 优化

- **每走一步的自动存盘不再卡界面**：首页「继续对局」靠的是对弈页每走一步就存一份当前棋局。以前这份存盘是在界面线程上当场把整局棋谱序列化并写进文件——棋局越长，每步要写的东西越大，落子瞬间就越容易顿一下。现在改为：最新棋局先同步记在内存里（首页卡片、备份导出读到的永远是最新状态），真正写文件由一条后台线程按顺序慢慢落盘。下棋落子不再等存盘，长局也一样。
- 存盘顺序有保证：下完棋立刻结束对局时，排队中的最后一次存盘不会把已经清掉的「继续对局」又写回来；首页卡片该消失还是消失。
