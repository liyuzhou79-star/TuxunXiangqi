# 将！ 1.0.0（候选版）

第一个功能完整的版本：能下、能分析、能复盘、能训练，全部在本机完成，不联网、不收费、没有广告。

## 主要功能

- **人机对弈**：内置 Pikafish 引擎（开源 UCI 引擎 + 官方神经网络评估），三档水平（休闲 / 普通 / 高手），可让子、可用棋钟、可以求和（引擎会判断局势再决定），AI 一选实时标在棋盘上
- **双人对弈与 AI 表演赛**：同一台手机两个人下，或让引擎自己跟自己下，看它对拆
- **形势分析**：前四个候选着法各自的胜率、优势和后续变化；连续分析每走一步自动刷新；局内走势图记录整盘的形势起伏，关键手一眼可见
- **开局库**：18 个常见定式节点，开局阶段自动给出走法建议
- **摆棋对弈**：自己摆任意局面（带合法性检查），接着和引擎或朋友下
- **棋谱与复盘**：对局自动保存；复盘时引擎逐步巡查、标出关键手并给出当时的一选对比；棋谱可导出为文本、分享局面图片，也可粘贴文本导入
- **猜一选训练**：看局面猜引擎的第一选择，三档难度外加「我的棋谱」出题和 30 秒限时挑战；猜错自动进错题本
- **残局训练**：24 道「红先胜」残局，引擎执黑防守兼当裁判，优势走没了当场提醒，带正解演示和每题最佳步数记录；每天一道「每日一题」
- **音效**：落子、吃子、将军、胜负短音效，全部由程序合成，不带音频文件，设置里可关
- **设置与数据**：深色模式、翻转棋盘、坐标与棋谱文字开关、专注模式；全部数据（棋谱、设置、训练进度）可导出备份文件再导入恢复；对局战绩单独统计
