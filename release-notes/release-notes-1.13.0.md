# 将！ v1.13.0 更新说明

这一版把「分析」在两个地方的用法统一了：复盘页的深度分析现在和对局页的分析面板长一个样、用法也一个样；同时棋谱多了也不怕翻不动，猜一选的成绩单也理顺了。

## 新功能

- **复盘深析也能试走变化**：以前复盘深析的候选只能点开看一眼箭头。这版每个候选都成了和对局页同款的卡片：点卡片切换棋盘箭头，点卡里的「试走这条线」，就能在棋盘上一步步把引擎给的后续变化摆出来看（上一步／下一步／退出试走），吃子栏会跟着试走局面走。试走只是看，不会改动棋谱；切换到别的步数会自动退出。

## 优化

- **分析交互全 App 一个口径**：对局页分析面板和复盘深析的候选卡——名次、着法、形势判断、后续变化、选中高亮、试走按钮——现在完全一致，在哪儿学会的用法，换个页面照样用。
- **棋谱库翻页更跟手**：棋谱列表改成按需加载，一次存几百局，打开和滑动也不会把所有卡片一口气全画出来；搜索和筛选照常即时响应。
- **猜一选本轮成绩不再混**：切换题目来源或开关限时挑战时，本轮成绩自动重新计，限时答的题和慢慢想的题不再混在一行里；累计成绩不受影响。

## 说明

- 本版是正式签名版，可直接覆盖 1.12.0 及更早正式版升级，棋谱和设置都保留。
- 深析结果和试走仍然只在复盘页面里有效，退出复盘即清空，不写入棋谱文件。
