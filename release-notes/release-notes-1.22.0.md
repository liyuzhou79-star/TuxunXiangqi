# 将！ v1.22.0 更新说明

这一版补上了一个容易被忽略的缺口：以前换手机时，棋谱和设置能跟着走，辛辛苦苦解出来的残局进度和猜一选成绩却会丢光。现在它们也进备份了。另外复盘页能直接把当前局面发成图片了。

## 改进

- **备份带上训练进度**：数据备份现在包含残局解题进度（解出了哪些题、哪些用过提示、每题的最佳步数）和猜一选的全部统计（各来源和限时挑战分开记的那套）。换手机恢复备份后，训练进度原样回来。用旧版本导出的老备份也能正常恢复，只是不会动你现在这台手机上的训练进度。
- **复盘页分享棋盘图**：复盘页的分享行多了「分享棋盘图」，把当前正看到的这一步局面截成图片发出去，和对局页的「分享局面」是同一套做法。翻到关键手发张图给朋友讨论，比发整段棋谱文本更直观。

## 说明

- 本版是正式签名版，可直接覆盖 1.21.0 及更早正式版升级，棋谱和设置都保留。
- 设置页里备份的说明文字已同步更新，写清了备份的具体内容。
