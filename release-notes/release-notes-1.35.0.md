# 将！ v1.35.0 更新说明

这一版是内容加深：内置开局库从 42 个定式节点扩到 48 个，六条常用线各再往下走一层，开局阶段能陪你走得更远。

## 新内容

- **开局库 42 → 48 节点**：顺炮（红出车后黑的应招）、中炮对屏风马横车（黑平车后红的三路续招）、中炮对屏风马进卒（黑补马后的局面）、仙人指路转中炮（黑补马后红的续招）、飞相局（黑出马后红的续招）、中炮对屏风马双马齐出（红炮进二后黑的应招），六条线各加深一层、每层带三个候选着法。
- 连带受益：从定式节点开局时，分析面板沿书面线续报定式的范围同步变深；开局库浏览页能直接搜到并预览这些新节点。

## 说明

- 新增着法全部先经本地规则校验（合法性与记谱逐手核对）才入库，与全库既有节点同一标准。
- 连带变化：猜一选「开局」题池由定式 4–6 手的局面派生，本次有三个新节点正落在这个范围，题池从 17 题增至 20 题（中炮对屏风马进卒、仙人指路转中炮、飞相局各多一道），每道都带定式线名。
- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
