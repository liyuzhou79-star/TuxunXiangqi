# 将！ v1.46.0 更新说明

残局题库扩充到六十九道。新增的四道全部先经过求解程序逐题验证、确认是红方强制杀才收录，延续题库「宁缺毋滥」的口径。

## 新增

- **第 66 题「马炮双兵胜士象全」**（马炮类，难度三星）：兵马炮三样配合，求解程序证明藏着一串六步的连环杀，和第 62 题并列本库最难。
- **第 67 题「双马双兵胜双士单象」**（双炮双马类，难度二星）：马踩点、兵压宫，四步之内见杀。
- **第 68 题「双车炮胜双士单象」**（双车类，难度一星）：车封路、炮轰士，两步之内见杀。
- **第 69 题「车炮马兵胜双士单象」**（车炮类，难度二星）：车炮马兵四件套轮着上，三步之内见杀。

四道新题同样支持解题记录、提示、演示与「下一道未解的题」直达，也进入每日一题的轮换池。

## 说明

- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
