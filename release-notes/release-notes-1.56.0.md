# 将！ v1.56.0 更新说明

开局库从 84 个定式节点扩充到 90 个，四条主线继续往深里走，最深的线路已经能陪你走完前十三手。

## 新增

- **顺炮线**：红方兵九进一之后黑方出车、进卒的应法入库；黑方进卒之后红方进兵、出车的续招也补齐了。
- **飞相局线**：黑方平车之后红方出马、进兵、出车的续招入库。
- **仙人指路转中炮线**：黑方进卒之后红方进兵、出车的续招入库。
- **中炮对屏风马线**：黑方平车之后红方进兵、出车的续招，以及黑方飞象之后红方进兵、出车的续招入库。

新增节点全部经过本地校验程序逐手核对：每一步历史着法、每一条建议着法都合法，建议的中文记谱与记谱生成器逐字一致。
