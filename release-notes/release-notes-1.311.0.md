# 将！ v1.311.0 更新说明

功能打磨第七版：给引擎通信层补了两个藏在底层的可靠性缺口。

## 修复

- **引擎重启后第一次计算不再偶发假报错**：以前引擎进程中途退出又被重新拉起时，旧进程残留的一条「已退出」信号可能迟到一步，混进新引擎的通信队列里，让新引擎的第一次计算误报「引擎中途退出了」——虽然再点一次就恢复，但看着像引擎坏了。现在每个引擎进程用自己独立的通信队列，旧进程的残留信号再也串不进新进程。
- **页面关掉的瞬间引擎请求不再有崩溃隐患**：以前在页面关闭、引擎正在关停的同一瞬间如果还有一个请求递进来，底层会直接抛异常。现在这类请求会被安静地拦下并给出明确的「引擎已关闭」回执，不会带崩页面。
