# 将！ v1.82.0 更新说明

开局库扩充到一百七十个定式节点；猜一选限时挑战的计分规则完成一次专项复核。

## 新增

- **开局库第二十轮扩充**：在一百六十四个节点的基础上再添六个，来到一百七十个，最深二十六手。顺炮等主线继续向后延伸，照库开局能陪你走得更远。

## 改进

- **限时挑战计分复核**：逐条核对了猜一选限时挑战的规则——30 秒倒计时只在题目未揭晓时走，到点自动按答错判定并收进错题本；每道题只计分一次，不会重复记账；限时题的成绩单独记在「限时挑战」一栏，不和普通练习混在一起；错题在挑战里答对了同样会移出错题本。复核结论：规则一致，无需改动。

## 说明

- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
