# 将！ v1.72.0 更新说明

开局库扩充到一百四十个定式节点，最深线路推进到二十一手；残局列表换了渲染方式，题目再多滑动也流畅。

## 新增

- **六个深层定式节点**：顺炮、飞相局、中炮对屏风马、仙人指路转中炮四条线继续向深处推进，最深处走到第二十、二十一手，定式页与对局中的定式续报都能跟到更深。

## 改进

- **残局列表按需渲染**：题库涨到一百二十五道后，原来的列表会把每一行都提前画好，滑动时容易发涩。本版改成只画屏幕上看得见的行（与棋谱库同款做法），内容、分组与顺序不变，滑动明显更跟手，筛选与「只看未解」行为不变。

## 说明

- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
