# 将！ v1.305.0 更新说明

本版起转向功能打磨：先修引擎管线里两处拖慢响应的问题。

## 修复

- **引擎走棋不再被未完成的分析拖住**：以前一步分析还没算完时，引擎的应招要排队等它算满全程（默认 2 秒）才开始。现在新的计算请求会立刻打断正在进行的旧分析，引擎应招和分析都只等自己的计算时间。
- **修掉一处引擎状态残留**：分析用过的多候选设置会残留到下一步走棋计算里，让引擎把时间花在维护多条变化线上、主线算得更浅。现在每次走棋计算都会把该设置复位，走棋只算它要走的那一步。

## 说明

- 对局各档位的思考时长与深度、棋力设置保持不变，本版只修计算管线。
- 残局题库 594 题、开局库 836 个定式节点保持不变。
