# 将！ v1.307.0 更新说明

功能打磨第三版：对弈页在分析时不再「冻住」。

## 修复

- **分析进行时棋盘恢复响应**：以前引擎分析（包括打开「自动分析」后每步自动跟算的那几秒）期间，落子、悔棋、重开、存谱、认输、求和全都被一起挡住，点什么都没反应。现在只有引擎自己思考应招的那一小段时间才挡操作；分析结果本来就会在局面变化后自动作废，不再拿它冻结整个棋盘。
- **「重开」按钮补上禁用态**：以前它在引擎思考时看起来能点、点了却没动静，现在与实际守卫一致，思考时明确置灰。

## 说明

- 对局各档位的思考时长与深度、棋力设置保持不变。
- 残局题库 594 题、开局库 836 个定式节点保持不变。
