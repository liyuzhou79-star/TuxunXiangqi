# 将！ v1.309.0 更新说明

功能打磨第五版：横屏和分屏下棋盘终于能完整看清了。

## 修复

- **横屏 / 分屏时棋盘不再高得看不全**：棋盘本身比宽还高，以前一律按屏幕宽度撑满，竖屏没问题，可一横屏（或上下分屏）棋盘高度就远远超出窗口，只能上下滑着看，永远看不到整盘棋。现在棋盘会按窗口高度自动封顶：横屏时整盘棋一次看全，棋盘在木框里居中显示。竖屏下的大小和以前完全一样，没有变化。
- 所有带棋盘的页面（对弈、残局、复盘、猜一选、摆棋、定式预览、新手指南）统一生效。

- 残局题库 594 题、开局库 836 个定式节点保持不变。
