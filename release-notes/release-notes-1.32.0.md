# 将！ v1.32.0 更新说明

这一版给每日一题加了「补做」：前几天的每日一题没解，也能找回来补上，连续天数不会白断。

## 新功能

- **每日一题近 7 天可补做**：残局页顶部多了一张「每日一题 · 近 7 天」卡，列出今天往前 7 天的每日一题，每道标着已完成还是还没解，当前连续完成天数也直接写在卡上。点任意一天就进那天的题。
- **补做按题的日期记账**：补做哪天的题，就按哪天算完成——昨天漏了、今天补上，连续天数照样接得上；但补做只认题目自己的日期，跳过昨天直接解今天，不会把昨天也填上。首页和战绩页的连续天数口径不变，三处数字同源。

## 说明

- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
