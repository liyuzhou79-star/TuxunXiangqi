- **第 56 题「双马炮胜士象全」**（双炮双马类，难度二星）：双马轮流踩点、炮在后封口，三步之内见杀。
- **第 57 题「车双炮胜双士」**（车炮类，难度一星）：车炮齐备对双士，杀已成形，一步定局。
