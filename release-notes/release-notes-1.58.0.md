# 将！ v1.58.0 更新说明

开局库从 90 个定式节点扩充到 96 个，四条主线继续往深里走，最深的线路已经能陪你走完前十四手。

## 新增

- **顺炮线**：黑方出车之后红方平车、进兵、出车的续招入库，顺炮最深线路推进到十四手；红方兵九进一之后黑方出车、平车、进卒的应法也补齐了。
- **飞相局线**：红方马八进七之后黑方出车、进卒的应法入库。
- **仙人指路转中炮线**：红方兵九进一之后黑方飞象、出车、进卒的应法入库。
- **中炮对屏风马线**：红方兵三进一之后黑方进卒、出车、进卒的应法，以及黑方飞象之后红方进兵的续招入库。

新增节点全部经过本地校验程序逐手核对：每一步历史着法、每一条建议着法都合法，建议的中文记谱与记谱生成器逐字一致。
