# 将！ v1.14.0 更新说明

1.13.0 把对局页和复盘页的分析候选统一成了同款卡片，这一版把训练面也补齐：猜一选的判卷结果、残局题的引擎提示，现在都用同一套候选卡片——在哪个页面学到的看法、点法，到处都一样。

## 新功能

- **猜一选判卷后是候选卡片了**：以前判卷结果下面只有几行文字。这版引擎的前四个候选各是一张卡片：一选／二选／三选／四选、着法记谱、形势判断、后续变化，一应俱全；点任意一张卡，棋盘上的箭头就换成那一步。你猜的那步如果进了前四，对应的卡片上会标着「你猜的这步」，对错一眼看清。
- **残局提示一次给前四个候选**：以前「提示一步」只给一选和一个箭头。这版提示会把引擎的前四个候选都摆成卡片：一选仍在状态行里写明，点任意候选卡，棋盘箭头随即切换，可以把几条路线都看过再决定走哪条。提示次数照旧——每轮 3 次，点一次提示算一次，引擎没给出结果不扣次数。

## 优化

- **训练面分析口径与全 App 统一**：候选卡片的名次说法、形势描述、变化行、选中高亮，对局、复盘、猜一选、残局四处完全一致；深色模式下同样走主题色，选中与未选中的区分和别处相同。

## 说明

- 本版是正式签名版，可直接覆盖 1.13.0 及更早正式版升级，棋谱和设置都保留。
- 残局提示的候选卡只在当前局面有效：走一步、悔棋、重开或开始演示，卡片就会收起，不会把旧局面的候选留到新局面里误导人。
