# 将！ v1.34.0 更新说明

上一版让深析结果和定式线名「存得下、带得走」，这一版把它们在界面上摆到顺手的位置：开局库的节点卡一眼能认出是哪条线，复盘页能直接跳到深析过的步，棋谱库能只列出做过深析的棋谱。

## 优化

- **开局库节点卡带线名标题**：节点卡的第一行改为所属定式的名字（中炮、顺炮、仙人指路、飞相局、对兵局），原来的着法序列降为小字副标题。在列表里扫一眼就知道每张卡是哪条线，不用点开逐手数。
- **复盘页「已深析的步」总览**：分析区多了一排跳转钮，列出这条棋谱里所有已经做过深度分析的步（包括以前存下、和导入时带进来的），点任意一步直接跳过去看深析卡，不用从头一步步翻。
- **棋谱库可只看有深析的棋谱**：筛选区新增「只看有深析的棋谱」开关，可与模式、结果、搜索、排序叠加使用；棋谱卡的信息行也会标出「深析 N 步」，哪些局深挖过一目了然。

## 说明

- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
