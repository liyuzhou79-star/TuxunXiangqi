# 将！ v1.36.0 更新说明

这一版是复盘与日常体验的补强：深析结果有了总览图，首页能一眼看到近一周的每日一题完成情况，棋谱库也多了一种找谱的方式。

## 新功能

- **复盘深析评分差小图**：复盘页的分析区新增一张柱状小图——每深析一步就多一根柱子，柱子高度是这一步实战着法比引擎深算一选差了多少：越高走得越亏，掉约 2.5 个兵以上的步会标成红色。点任意一根柱子就能跳到那一步细看。实战着法没进深析前四时，用整局分析的评分差补上，口径在图下写明。
- **首页每日一题近 7 天点阵**：首页今日一题卡片里加上近 7 天的完成点阵（和战绩页同源）：实心点是当天解出来了，今天带圈标着，底下是星期。这一周有没有断签，打开首页就知道。
- **棋谱库按开局来源筛选**：棋谱库筛选区新增一排「来源」分段按钮——全部／标准／定式／摆棋，按每局的起始局面分类（标准开局、从开局库定式开的局、在摆棋页摆出来的局），可以和模式、结果、搜索、排序任意叠加。

## 说明

- 残局题库本版没有扩容：新增题面必须先过本地规则校验、并有可靠的经典谱面依据，宁缺毋滥，后续核实到位再加。
- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
