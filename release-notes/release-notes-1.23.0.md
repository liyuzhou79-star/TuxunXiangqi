# 将！ v1.23.0 更新说明

这一版给棋谱补上了「这局是从哪儿开的」：以前棋谱只记模式和结果，从定式局面摆开的局、自己摆棋开的局混在一起看不出来。现在每局都按初始局面标明了来源。另外把猜一选错题重练时的提示话说清楚了。

## 改进

- **棋谱标明开局来源**：棋谱库里每张卡片都会标明这局的开局来源——「标准开局」「定式开局」还是「摆棋开局」，按初始局面自动判定，老棋谱也一样适用。在棋谱库搜索框里输入「定式」或「摆棋」，就能只找出对应来源的对局。
- **复盘页同样标明来源**：复盘页标题下也会显示来源；定式开局的还会把定式走法一并写出来（例如「炮二平五 · 马8进7」），一眼就知道这局是从哪条定式线摆开的。
- **错题重练的提示说清楚了**：在猜一选里重练错题时，猜中一选会明确告诉你「这题已移出错题本」；没猜中时也会说明「这题继续留在错题本里」，不用再自己猜这题到底还在不在本里。

## 说明

- 本版是正式签名版，可直接覆盖 1.22.0 及更早正式版升级，棋谱和设置都保留。
- 开局来源是按初始局面判定的：自己摆棋时如果正好摆出定式局面，会按定式开局显示。
