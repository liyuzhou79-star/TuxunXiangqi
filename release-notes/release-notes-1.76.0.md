# 将！ v1.76.0 更新说明

开局库扩充到一百五十二个定式节点；摆棋的合法性校验补上子力数量上限。

## 新增

- **开局库第十七轮扩充**：在一百四十六个节点的基础上再添六个，来到一百五十二个，最深二十三手。顺炮等主线继续向后延伸，照库开局能陪你走得更远。

## 修复

- **摆棋能放出超编的棋子**：摆棋盘上放棋子一直不数数量——可以放两个红帅、三个黑炮、六个兵，校验也不拦，照样能开局。这样的局面规则层和引擎都没法正常处理。本版补上数量上限校验（将帅每方一个，车马炮仕象每方最多两个，兵卒最多五个），超了会直接写明哪种棋子多了几个，改对才能开局。正常摆法与经典残局局面不受影响。

## 说明

- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
