# 将！ v1.62.0 更新说明

## 新增

- **顺炮线**：黑方平车之后红方进兵、出炮的续招入库，顺炮最深线路推进到十六手；红方平车之后黑方平车、进卒的应法也补齐了。
- **飞相局线**：黑方进卒之后红方进兵、出炮的续招入库。
- **仙人指路转中炮线**：红方兵七进一之后黑方出车、进卒的应法入库。
- **中炮对屏风马线**：红方兵九进一之后黑方出车、进卒的应法，以及红方兵九进一之后黑方出车、进卒的应法入库。

新增节点全部经过本地校验程序逐手核对：每一步历史着法、每一条建议着法都合法，建议的中文记谱与记谱生成器逐字一致。
