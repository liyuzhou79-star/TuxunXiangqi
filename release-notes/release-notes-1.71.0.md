# 将！ v1.71.0 更新说明

残局题库扩充到一百二十五道；同时对全部题目做了一次全量审计，换掉了一道重复题。

## 新增

- **第 122 题「双车双炮四兵胜士象全」**（双车类，难度一星）：两步之内见杀。
- **第 123 题「马双炮五兵胜双士」**（马炮类，难度二星）：马炮带满五兵，四步之内见杀。
- **第 124 题「双马双炮四兵胜士象全」**（双炮双马类，难度二星）：四步之内见杀。
- **第 125 题「车双炮五兵胜士象全」**（车炮类，难度一星）：两步之内见杀。

四道新题全部先经过求解程序逐题验证、确认红方必胜才收录，延续题库「宁缺毋滥」的口径。

## 修复

- **第 108 题换新**：全量审计发现原第 108 题与第 100 题是同一个局面——同一道题曾在不同批次里被收录了两次，只是标题不同。本版为第 108 题换上一道新的「车马双炮四兵胜士象全」（车马类，难度二星，同样经求解程序验证、四步之内见杀）；题号、分类与难度不变，已有的解题进度不受影响。

## 改进

- **题库去重自检入册**：新增一项自动检查——题库里任意两道题的局面不得相同，重复收录会直接让构建失败，这类问题以后不会再漏网。

## 说明

- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
