# 将！ v1.3.0 更新说明

## 新功能

- **棋力细调**：人机对弈设置里多了一个 1–10 的「棋力细调」滑杆，在三档难度之上再细调引擎强弱，界面会直接写清当前每步大约想多久、最深算多少层。先把话说在前面：Pikafish 引擎本身没有强弱档——它的全部设置项我们逐项实测核对过，没有限强、没有 Elo 设置——所以这个细调是拿思考时间和搜索深度模拟出来的，数字越小它想得越少、越像新手，数字越大越强。选择会记住，下次打开还是你调好的值。
- **开局库扩容**：定式节点从 18 个增加到 30 个，中炮、顺炮、仙人指路、飞相局几条主线都往深里补了几步，开局阶段的走法建议更跟得上了。
- **残局题扩容**：残局题从 24 道增加到 32 道，新增双车马、车炮双兵、车带三兵、双车对马炮等八道「红先胜」，每道题的局面都经过逐项校验（双将齐全、不照面、开局不被将军）。

## 修复

- **开局库名称写反修正**：审计发现开局库里几处定式名称和实际着法对不上——「兵七进一（仙人指路）」和「相三进五（飞相局）」的首步此前记在了另一侧，顺炮线里黑方两门炮的文件名也标反了，几处车的着法名同样互换。着法本身都合法，所以一直没被发现；这次全部按记谱规则逐条改正，并给开局库加了一条新测试：每条建议的名字都要和 App 自己生成的记谱一字不差，今后写反会被当场拦下。
