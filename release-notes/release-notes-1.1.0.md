# 将！ 1.1.0

这一版专攻对局页的手感和质感：棋盘、棋子、标记、字体、声音全部重做或升级，资源都来自可自由转载的开源与公共素材，并在 App 的设置页和仓库里写明了出处。

## 新功能

- **落子动画**：棋子不再瞬移——走棋时棋子会滑到新位置，途中微微抬起、落定回位，配合落子声，一步棋有了分量
- **真人录音音效**：落子、吃子、获胜、落败、和棋换成真实录音（来自开源象棋项目 ChessRoad，GPL-3.0），不再是程序合成的电子音；将军提示仍为短促的合成双响

## 优化

- **棋盘与棋子质感**：棋盘面和边框用上真实胡桃木纹理照片（Wikimedia Commons，CC BY-SA 3.0），叠上光影渐变和边缘暗角；棋子加了侧面厚度、倒角高光和投影，字面带凹刻浮雕感，不再是平贴的圆片
- **棋子书法字**：全部棋子字和「楚河漢界」换成莫大毛筆體（Bakudai，SIL OFL 1.1 开源字体）的粗笔书法字，和 JJ 象棋那类毛笔字是一路风格；字体只打包用到的 17 个字，仅约 11 KB
- **落子标记改样式**：按用户反馈改掉原来的两个大框——现在新位置是棋子周围一圈白色光晕环，原位置只留一个白色发光小点，一眼看清从哪来到哪去
- **资源鸣谢进 App**：设置页新增「资源与鸣谢」，字体、木纹、音效、引擎的出处在 App 里就能看全

## 修复

- **去掉棋盘印刷的兵炮位拐角标记**：这些小框印在棋盘上，棋子走开后还留在原地，看着像没清干净的残影；本版直接取消，棋盘更干净。同时逐路核查了落子标记的状态清除（悔棋、重开、吃子后旧标记都会正确清掉）

## 说明

- 本版使用正式签名发布，可直接覆盖安装 1.0.0 正式版
- 将军的真人语音喊声找遍了许可证清晰的开源来源，候选包经核实都是合成音、没有真人录音，本版不拿机械合成腔充数；找到合适的真人录音后再补上
- 除「检查更新」需手动点击联网外，App 不进行任何网络访问
