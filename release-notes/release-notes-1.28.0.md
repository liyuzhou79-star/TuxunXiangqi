# 将！ v1.28.0 更新说明

这一版是训练专版：猜一选的题池变大了，每日一题开始记连续完成天数，坚持打卡更有奔头。

## 新功能

- **每日一题连续天数**：解出每日一题后，App 会把这一天记下来；首页的每日一题卡上会显示「每日一题已连续完成 N 天」。今天还没解时，截至昨天的连续记录不会清零，当天解出就续上。连续天数也会进数据备份，换手机恢复后接着算（老备份没有这项记录，恢复时不会冲掉本机的天数）。
- **猜一选题池扩容**：简单、普通、困难三档从每档 8 题扩到每档 12 题，共 36 题。新题面都选自残局题库的经典局面（车马炮胜士象全、车马对双炮双士、车带三兵等），同一档里没有重复局面，来源按钮上的题量数字会跟着变。

## 说明

- 连续天数从这一版开始记录，此前解过的每日一题没有日期记录，无法追溯补算。
- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
