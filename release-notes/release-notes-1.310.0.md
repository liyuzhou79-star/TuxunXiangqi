# 将！ v1.310.0 更新说明

功能打磨第六版：修了复盘页一个藏得挺深的互相打架问题。

## 修复

- **整局分析期间，「和引擎一选对比」不再捣乱**：以前整局批量分析正在跑的时候（长棋谱要跑上一两分钟），这个按钮还能点。一点下去，它会把批量分析正在算的那一步抢断，那一步的评分就悄悄丢了；紧接着批量分析的下一步又把对比抢断，对比还会误报一句「引擎暂时没给出候选」。现在三者（整局分析、深度分析、一选对比）彻底互斥：谁在跑，另外两个按钮就先禁用，函数内部也再挡一层。
- **对比被打断时的提示改对了**：万一对比被别的分析打断，现在会如实提示「被打断了，请再点一次」，不再误报成引擎没给出候选。

- 残局题库 594 题、开局库 836 个定式节点保持不变。
