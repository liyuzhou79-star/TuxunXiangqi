# 将！ v1.9.0 更新说明

这一版补上了一个早就该有的能力：下到一半的棋不会再丢了。另外修了一个藏得很深的棋钟问题。

## 新功能

- **中途存档、随时续下**：人机对弈和人人对弈现在每走一手就自动把进度存好，退出对局页、切到别的 App、甚至关掉重开，都不会丢。回到首页会看到一张「继续对局」卡，写明是什么模式、已下多少手，点「接着下」就回到离开时的局面——难度、执红执黑、让子、棋力细调、棋钟和双方剩下的时间、已经算过的形势分数，全都原样恢复。不想下了点「放弃这局」即可。对局正常结束或点重开时，存档会自动清掉，不会留下一张过期的卡。表演赛是观看用的，不参与存档。

## 修复

- **人人对弈带棋钟会瞬间判超时**：如果在设置里给对局预设了棋钟（比如 10 分钟），进人人对弈会立刻判先手超时——人人对弈没有开局设置环节，钟面从 0 开始没人初始化，棋钟一走就判负。这一版把钟面初始值改成按设定的分钟数生成，人人对弈带钟开局正常了。人机对弈走设置流程确认，原本不受影响；没设棋钟（不限时）时也不会触发，所以这个问题一直没被发现。

## 说明

- 「将军」的真人叫声搜寻进行到第九轮：这一轮用代码搜索扫了公开仓库里的将军音文件（唯一命中是一部电视剧的配乐，无关），又实查了三个带开源许可证的新象棋仓库——olivanderwood/xiangqi（MIT，只有落子／吃子音）、weilunyuan/NinePalace（MIT，没有音频）、benckx/elephantchess（GPL-3.0，音频是几段通知音效）。都没有真人将军声，照旧不拿合成音充数，搜寻常驻继续。绝杀的真人喊声已在 1.6.0 上线，不受影响。
- 本版是正式签名版，可直接覆盖 1.8.0 及更早正式版升级，棋谱和设置都保留。
