# 将！ v1.27.0 更新说明

这一版补量又补顺手：残局题库从 32 题扩到 40 题，复盘的走势图能直接点着跳步，FEN 局面的导入导出也补齐了最后几处。

## 新功能

- **残局题扩容到 40 题**：新增 8 道经典例胜——双车胜士象全、车马炮胜士象全、双马炮胜士象全、车双兵胜士象全、马炮双兵胜士象全、双车胜马炮双士、车炮胜双马、马兵胜单炮。分类和难度星级都已配好，老规矩：引擎当裁判，走得出真正赢棋的线都算解出。每日一题的轮换池也随之变大。
- **复盘走势图可以点了**：以前走势图只能看，现在点图上任意位置，就会跳到离那儿最近的一步，棋盘、着法表和图上的定位圈一起跟上；自动播放会先停下。配合着法片和「下一关键手」，长局复盘翻找关键步更快。
- **复盘页能复制当前局面的 FEN**：分享行新增「复制当前局面 FEN」，翻到哪一步就复制哪一步的局面，发给朋友或存下来摆着研究都方便。
- **棋谱导入认得 FEN 了**：往棋谱库的导入框里粘贴一段 FEN（比如从别处抄来的局面），以前只会提示没认出，现在会识别出来并给出「去摆棋页打开这个局面」，点一下就摆好，还能直接从这个局面开局对弈。

## 说明

- 新增残局题的解题进度、备份恢复都和原有 32 题共用同一套记录，不受影响。
- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
