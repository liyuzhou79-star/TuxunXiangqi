# 将！ v1.73.0 更新说明

残局题库扩充到一百二十九道；定式页换了渲染方式，一百四十个节点打开也利落。

## 新增

- **第 126 题「双车双马五兵胜士象全」**（双车类，难度一星）：子力压倒，稳步收官。
- **第 127 题「车双马双炮四兵胜双士」**（车马类，难度一星）：两步之内见杀。
- **第 128 题「双炮四兵胜双士」**（双炮双马类，难度二星）：四步之内见杀。
- **第 129 题「车炮五兵胜士象全」**（车炮类，难度一星）：子力压倒，稳步收官。

四道新题全部先经过求解程序逐题验证、确认红方必胜才收录，延续题库「宁缺毋滥」的口径。

## 改进

- **定式页按需渲染**：开局库涨到一百四十个节点后，定式页原来会把页首的预览棋盘和每一张节点卡都提前画好，打开时不够利落。本版改成只画屏幕上看得见的部分（与残局列表、棋谱库同款做法），内容与顺序不变；点任意节点后自动滚回页首看棋盘的行为保持不变。

## 说明

- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
