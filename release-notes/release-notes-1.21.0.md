# 将！ v1.21.0 更新说明

这一版给棋谱库加了排序，摆棋编辑器能拿 FEN 进出局面，首页的每日一题卡会直接告诉你今天这题解没解。

## 新功能

- **棋谱库排序切换**：棋谱页多了一排排序选项——最新在前、最早在前、手数多到少、手数少到多、按标题。想找那盘下了两百手的长局，或者按时间从头回看自己的棋，点一下就排好；和模式筛选、结果筛选、搜索词可以叠加使用，多选管理的「当前列表」也跟着排序走。
- **摆棋编辑器 FEN 复制/分享/导入**：编辑器里多了一张 FEN 卡，摆好的局面随时显示对应的 FEN 文本，可以一键复制或分享给朋友；朋友在自己的编辑器里点「粘贴 FEN 摆棋」就能摆出一模一样的局面。从别处抄来的 FEN 也能粘贴进来，先看看局面再决定怎么下。编辑器仍然固定红方先行。
- **首页每日一题状态直显**：首页的今日一题卡会直接标注「今天这题你已经解出来了」，用过提示解出的也会如实标注，按钮随之变成「再练一次今日一题」，不用点进去才知道今天练没练。

## 说明

- 本版是正式签名版，可直接覆盖 1.20.0 及更早正式版升级，棋谱和设置都保留。
- 粘贴进来的 FEN 如果行数或字符不对，会明确提示没认出来，不会把棋盘摆乱。
