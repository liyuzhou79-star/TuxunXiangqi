# 将！ v1.8.0 更新说明

这一版是训练模块的深化：限时挑战的成绩开始单独记账，战绩页能看每类残局的进度了。

## 优化

- **猜一选限时成绩单列**：以前开着限时挑战（30 秒）答的题，成绩混在题目来源的档里，分不清哪些是抢时间抢出来的。从这一版起，限时模式下答的题单独记一桶：训练页的累计成绩下面多一行「限时挑战累计」，战绩页的训练进度里也单列一行（答题数、一选命中率、进前四次数）。普通模式的各档成绩从此只记不限时的题，两边都更准。注意：这一版之前已经答过的限时题没法追溯拆分，单列从本版开始累计。
- **战绩页残局按分类看进度**：训练进度里除了总数，还逐组列出六类残局（双车／车马／车炮／车兵／马炮／双炮双马）各自已解几题、共几题，哪一类是短板一眼就看出来，挑题补课更有方向。
