# 将！ v1.45.0 更新说明

开局库从 54 个定式节点扩充到 60 个，四条主线继续往深里走，最深的线路已经能陪你走完前九手。

## 新增

- **顺炮线**：补上炮八进二之后黑方的平车、进卒、出车应法，以及再往深一层的红方续招。
- **中炮对屏风马线**：车一平二、卒7进1之后，红方炮八进二、兵三进一、兵七进一的续招入库；进卒支线平车之后的续招也补齐了。
- **仙人指路转中炮线**：黑方飞象之后，红方炮八进二、马八进七、兵三进一三种走法入库。
- **飞相局线**：黑方车9平8之后，红方进兵、出车的续招入库。

新增节点全部经过本地校验程序逐手核对：每一步历史着法、每一条建议着法都合法，建议的中文记谱与记谱生成器逐字一致。校验还拦下两条初稿里下不出来的建议（落点被自家棋子占着），改对了才入库。

## 说明

- 猜一选的开局题池取材范围不变（仍取定式走了 4–6 手的局面），题量维持 20 道；这次加深的仍是 7 手以后的节点。
- 残局题库维持六十五道，全部经过求解程序审计。
- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
