# 将！ v1.25.0 更新说明

这一版把全 App 的页面按 Material 3 规范认真整改了一遍：层级更清楚、控件更统一，看起来和用起来都更像一个标准的 Material 3 应用。功能和对局棋力没有任何变化。

## 改进

- **每个子页面都有了标准顶栏**：棋谱库、复盘、残局、猜一选、开局库、战绩、设置、新手指南，进入后顶部是统一的标题栏加返回箭头；页面里不再重复写一遍大标题，底部也不用再拉到最下面找「返回」按钮。对局页和摆棋页原来的文字箭头也换成了标准图标。
- **单选改成分段按钮**：棋谱库的分类／结果／排序、残局的难度筛选、猜一选的题目来源、设置里的主题／默认难度／默认棋钟、对局设置里的执红执黑／引擎档位／棋钟、表演赛速度——原来都是一排圆角小片，现在统一换成 Material 3 的分段按钮，一行选定、选中态清楚。选项太多或标签太长的（让子档位、画面开关）保留原来的小片样式，那种场景小片更合适。
- **残局列表改成标准列表行**：整行可点直接进题，已解出的题行首有对勾标记，行与行之间用分隔线，不再是一张张卡片加按钮。
- **主题色板补全**：补齐了第三色、错误色、反色等之前缺失的 Material 3 色彩角色，深色模式下各处提示与横幅的颜色更一致；卡片和背景之间的明暗层级保持分明，不靠描边硬撑。
- 棋谱搜索框加上了搜索图标。

## 说明

- 棋盘本身不在这次整改范围内：木质棋盘和棋子是游戏向的专门绘制，保持原样。
- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
