# 将！ v1.12.0 更新说明

这一版继续打磨 1.11.0 上线的复盘深度分析：结果不再「看过就没」，候选着法可以直接在棋盘上点开看箭头；战绩页也把用过提示的残局成绩单列出来。

## 优化

- **深析结果按步留存**：以前深度分析的结果只留一份——换一步再深析，前一步的结果就被覆盖了；想回头看，只能再等引擎算 2 秒。这一版把每一步的深析结果分别存好：翻回之前深析过的步数，结果卡直接出现，不用重算；深析过程中切到别的步数也不会把结果弄丢，算完会自动存到对应的步数下。
- **深析候选点选预览**：深析结果卡里的四个候选现在可以点——点哪个候选，棋盘上就画出那一步的箭头，方便对照着看「第二选、第三选到底走哪」；被点中的候选会变色标出来，再点一次取消预览，回到一选箭头。
- **战绩页单列提示解出**：「训练进度」里会写清解出的残局中有几题用过提示，和残局列表里的「提示解出」标记对得上，成绩更诚实。

## 说明

- 本版是正式签名版，可直接覆盖 1.11.0 及更早正式版升级，棋谱和设置都保留。
- 深析结果和以前一样只存在复盘页面里，退出复盘即清空，不写入棋谱文件。
