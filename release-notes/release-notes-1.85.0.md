# 将！ v1.85.0 更新说明

摆棋编辑全面放开；引擎对弈不会再中途退出。

## 改进

- **摆棋想怎么摆就怎么摆**：编辑器不再拦任何摆法——缺将、双帅、六个兵、仕/士放出九宫、相/象过河、将帅照面，全部可以直接点开局。摆棋就是个自由沙盘，想试什么怪局面都行。
- **引擎不会中途退出**：以前在一些局面里引擎会答不上着法，对局卡住只能重开。现在引擎没算出着法时，会按本地规则替它走一步，棋局一直下到真正的将死或困毙；哪怕局面对它再不利，它也不会按分数提前认输。
- **求和由你说了算**：向引擎求和不再看局势——点「求和」这一局就以和棋结束，引擎不会因为自己占优就拒绝。

## 说明

- 一局棋结束的方式只有四种：真将死/困毙、你主动认输、双方和棋、棋钟超时。
- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。棋谱导入的合法性检查也保持不变——那是防止坏棋谱进库的另一道门，和摆棋无关。
