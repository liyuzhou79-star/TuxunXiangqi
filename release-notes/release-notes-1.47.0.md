# 将！ v1.47.0 更新说明

残局题库扩充到七十三道。新增的四道全部先经过求解程序逐题验证、确认红方真胜才收录，延续题库「宁缺毋滥」的口径。

## 新增

- **第 70 题「车双马双兵胜双士」**（车马类，难度一星）：一车带双马双兵，子力豪华，两步之内见杀。
- **第 71 题「双炮马兵胜双士」**（双炮双马类，难度一星）：炮借马腿、兵压中路，两步之内见杀。
- **第 72 题「炮马双兵胜双士」**（马炮类，难度二星）：子力不多、赢在配合，两步之内藏着杀。
- **第 73 题「车马双兵胜双士单象」**（车马类，难度一星）：子力占优，先敲守子再收官。

四道新题同样支持解题记录、提示、演示与「下一道未解的题」直达，也进入每日一题的轮换池。
