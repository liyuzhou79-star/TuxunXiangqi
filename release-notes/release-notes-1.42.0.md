# 将！ v1.42.0 更新说明

开局库从 48 个定式节点扩充到 54 个，四条主线都往深里多走了一层，开局阶段能陪你走得更远。

## 新增

- **中炮对屏风马线**再深两层：红方炮八进二、车一平二之后，黑方飞象、进卒、平车的常见应法都收进了库里；屏风马进卒的那条支线也补上了车一平二之后的黑方应法。
- **顺炮线**补上横车之后的续招：黑方车9平8之后，红方炮八进二、兵三进一、兵七进一三种走法都有据可查。
- **仙人指路转中炮线**：红方马二进三之后，黑方飞象、进卒、出车的应法入库。
- **飞相局线**：红方车一平二出车之后，黑方平车、进卒的应法入库。

新增节点全部经过本地校验程序逐手核对：每一步历史着法、每一条建议着法都合法，建议的中文记谱与记谱生成器逐字一致，不会再出现「书上写的走法其实下不出来」的情况。

## 说明

- 猜一选的开局题池取材范围不变（仍取定式走了 4–6 手的局面），题量维持 20 道；这次加深的是 7 手以后的节点，不影响题池。
- 残局题库维持五十七道；存量残局的深审复核仍在后台进行，有确认结论再如实同步。
- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
