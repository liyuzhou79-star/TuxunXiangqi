# 将！ v1.18.0 更新说明

这一版补上 1.16.0 的一个小尾巴：从开局库里开的局，分析面板现在能接着往下报定式了。

## 优化

- **开局库开局续报定式**：1.16.0 起可以从开局库的任意局面直接开局，但那种局的分析面板里「开局库」一栏是空的——它只认从标准起始局面走出来的棋。这版把选中定式线的历史一并带进对局：只要你接下来的走法还在库里的线上，分析面板就继续给出该局面的定式建议（点一下照样在棋盘上标箭头）；一旦走出库里没写的线，提示就如实消失，和从头开的局一个规矩。
- **标准开局不受影响**：从首页正常开的局，开局库引用和以前完全一样；摆棋编辑器开的局本来就不在定式线上，仍然不报，不会硬凑。

## 说明

- 本版是正式签名版，可直接覆盖 1.17.0 及更早正式版升级，棋谱和设置都保留。
- 定式数据本身没有增删，仍是内置的 30 个节点、86 条建议。
