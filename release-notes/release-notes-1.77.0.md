# 将！ v1.77.0 更新说明

残局题库扩充到一百三十七道；每日一题的日期逻辑完成一次专项复核。

## 新增

- **第 134 题「双马五兵胜士象全」**（双炮双马类，难度一星）：子力压倒，稳步收官。
- **第 135 题「车双马四兵胜双士」**（车马类，难度一星）：两步之内见杀。
- **第 136 题「双炮五兵胜士象全」**（双炮双马类，难度一星）：子力压倒，稳步收官。
- **第 137 题「马炮五兵胜双士」**（马炮类，难度一星）：子力压倒，稳步收官。

四道新题全部先经过求解程序逐题验证、确认红方必胜才收录，延续题库「宁缺毋滥」的口径。

## 改进

- **每日一题跨年复核**：每日题按「一年中的第几天」轮换，跨年那一周（12 月底到 1 月初）序号会从 365/366 跳回 1。本次专项复核确认：跨年前后一周的七道题仍然互不重复、补做入口与连续天数计算都不受影响，并把普通年份与闰年的跨年情形都写进了自动测试，今后题库再扩容也会自动复查这一条。

## 说明

- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
