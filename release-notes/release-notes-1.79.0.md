# 将！ v1.79.0 更新说明

残局题库扩充到一百四十一道；生涯页的胜负统计口径完成一次专项复核。

## 新增

- **第 138 题「双车炮四兵胜士象全」**（双车类，难度一星）：子力压倒，稳步收官。
- **第 139 题「车炮三兵胜士象全」**（车炮类，难度一星）：子力占优，稳步收官。
- **第 140 题「马炮三兵胜士象全」**（马炮类，难度二星）：五步之内见杀，手筋要算准。
- **第 141 题「双马三兵胜双士」**（双炮双马类，难度一星）：两步之内见杀。

四道新题全部先经过求解程序逐题验证、确认红方必胜才收录，延续题库「宁缺毋滥」的口径。本批刻意收了几道子力更省的题，杀法步数拉长，不再全是速胜局。

## 改进

- **生涯统计口径复核**：生涯页的胜率、分档位与分执红/执黑统计，都是按棋谱里记的模式与结果文字归类的。本次逐条核对：这些文字全局只有一处生成、措辞稳定，让子局的附加文字不会干扰执红执黑的判断，没下完的对局不会被算成胜负。顺手把归类逻辑从页面里抽出来、写进自动测试——今后谁改了对局结果的措辞，测试会立刻报警，不会再出现统计悄悄算错的情况。

## 说明

- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
