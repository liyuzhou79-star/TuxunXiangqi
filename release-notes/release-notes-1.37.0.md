# 将！ v1.37.0 更新说明

这一版做了一次残局题库的全面体检，外加三处找东西、看进度的补强。

## 题库体检与修正

- **48 道残局逐题复核**：用规则求解程序把题库里每一道「红先胜」都重新验了一遍——能在搜索范围内证出杀棋或压倒性优势的，全部通过。
- **修正一道题面**：原第 46 题「马炮胜双马」复核时发现红方并无可证的胜势（马炮对双马、双方无兵过河，最佳防守下只是均势，摆在「红先胜」题库里名不副实）。已就地换成一道同类题「马炮带兵胜单马」，新局面经过同一程序深验，红方有强制杀棋。题号不变，已解记录不受影响。
- 少数长打收官型的经典例胜（如马炮胜士象全、马兵胜士象全）靠的是几十步的耐心收网，程序的搜索深度内无法证完，也没有发现反例，保持原样；实际对局中仍由引擎当裁判判定。

## 改进

- **残局列表分类进度条**：残局页每个分类的标题下加了进度条，和标题上的「已解 N」同一数字，这一类练到几成一眼可见。
- **开局库按线名搜索**：开局库浏览页的搜索现在也能按定式线名找——比如搜「顺炮」，能把顺炮线深处、建议里没写线名的节点也一并找出（此前只能搜到建议名里带线名的节点）。

## 说明

- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
