# 将！ v1.10.0 更新说明

这一版不加新功能，专门做瘦身和逐页检查：把全套图标换成更小的 WebP 格式，再把每个页面在小屏和深色模式下逐项核对一遍。

## 优化

- **安装包瘦身约 0.9 MB**：首页的应用图标图、桌面启动图标（五档密度）、圆形图标，原来都是 PNG，合计近 1 MB；这一版全部换成 WebP 格式（画质按高规格压的，肉眼看不出差别），合计不到 100 KB。棋盘的木纹图试过重压，结果反而更大——原图已经是最优编码了，所以保持不动，棋盘质感不受任何影响。
- **逐页小屏／深色复核**：对局页、复盘页、猜一选、残局、棋谱库、战绩、指南、设置、关于等页面逐页核对——所有页面都保持单一滚动容器，长文字换行不截断；对局页中栏在矮屏上本来就是可滚动列，本轮再次确认棋盘下方的走势图、吃子栏、按钮区都能滑到。深色模式下各页面的卡片、按钮、标记颜色逐项核对，没有发现看不清或串色的地方。
