# 将！ 1.2.0

这一版继续打磨对局页：选子时一眼看清每步的安危，吃掉的子整齐列在棋盘下方，将军时被将的那颗将/帅会醒目地提醒你。

## 新功能

- **落点安危提示**：选中棋子后，落点按安危分色——绿点＝落过去安全，红点＝落过去会被吃掉（送死）；能吃的子，绿圈＝吃完安全，没标记＝吃完会被反吃。判定由本地规则即时算出，点中棋子的同一帧就画出来，不联网、不等引擎。设置里可关，关掉回到只标落点的老样子
- **吃子展示栏**：棋盘下方成列展示双方已经吃掉的子（强的在前），并标出子力占优的一方约合几个兵；悔棋、重开都会自动跟着对齐，不用手动维护
- **将军反馈强化**：将军时，被将一方的将/帅周围多了一圈呼吸般的红色脉冲环，配合将军音效，一眼定位危险

## 优化

- **落子动画与标记衔接**：落点白色光晕随棋子滑行进度淡入，不再提前亮起；音效加了并发保护，快速连下、表演赛快速档也不会叠成一团

## 修复

- **悔棋时棋子误滑行**：1.1.0 的落子动画在悔棋后会把上一手的棋子再滑行一遍（动了没碰过的子）；本版改为只有真正落子时才触发动画，悔棋、重开、摆棋开局都干脆利落

## 说明

- 本版使用正式签名发布，可直接覆盖安装 1.1.0 正式版
- 将军的真人语音喊声：本版又扩大范围找了一轮（多个开源象棋项目的音频包逐个用语音识别加频谱核实），候选文件都是合成音效、没有真人录音，按既定口径不拿合成腔充数；找到干净的真人录音后会第一时间补上
- 除「检查更新」需手动点击联网外，App 不进行任何网络访问
