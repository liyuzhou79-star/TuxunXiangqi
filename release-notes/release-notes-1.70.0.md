# 将！ v1.70.0 更新说明

开局库扩充到一百三十四个定式节点，最深线路推进到二十手；同时对全库做了一次结构审计，修好顺炮线上一处断裂。

## 新增

- **六个深层定式节点**：顺炮、飞相局、中炮对屏风马、仙人指路转中炮四条线各有推进，最深处走到第十九、二十手，定式页与对局中的定式续报都能跟到更深。
- **猜一选「开局局面」题池二十一题**：随开局库修复新增一个四手局面，题池由二十题增至二十一题。

## 修复

- **顺炮线两个缺失的中间节点**：此前顺炮线在「炮二平五、炮8平5」之后直接跳到了更深的节点，中间两层没有写进库里——从定式页逐层往下翻会断档，对局走到这两层时也报不出定式。本版把缺失的两层补齐，整条线从头到尾连通。
- **中炮后黑方「炮2平5（顺炮）」衔接缺失**：这个节点本身在库里，但上一层的建议里没有这一招，等于藏在线外，一并补上。

## 改进

- **开局库结构自检入册**：新增一项自动检查——库里每一个节点都必须能从根节点沿着建议着法一步步走到，断链会直接让构建失败，这类缺失以后不会再悄悄漏网。

## 说明

- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
