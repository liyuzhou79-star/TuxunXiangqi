# 将！ v1.6.0 更新说明

这一版最大的事：找了六轮的真人叫杀声，终于有着落了——先落地一半。另外训练模块做了两处深化，表演赛的速度也会被记住了。

## 新功能

- **绝杀有真人喊声了**：对局以将死或困毙结束时，会响起一声真人喊的「绝杀！」（残局题解出时同样）。这段录音来自开源安卓象棋项目 chinese-chess-fish（作者 zfdang，MIT 许可），入库前用语音转录加频谱／共振峰分析双路核实过：两个转录模型都听出是中文双字喊声，基频轨迹是真人喊嗓的自然起伏，频谱饱满度也落在人声区间，确认是真人录音而不是合成音。认输、超时、和棋等其他终局方式仍用原来的胜负音，不会乱喊。
- **残局按题材分类＋难度星级**：三十二道残局现在按进攻主角分成六组——双车类、车马类、车炮类、车兵类、马炮类、双炮双马类，列表按组展示并显示每组已解进度；每道题标了难度（★ 子力碾压、★★ 经典例胜、★★★ 稀子或耐心局），挑题时心里有数。
- **猜一选有累计成绩了**：每次判卷都会记进累计统计（按简单／普通／困难／我的棋谱／错题本分开记）：总答题数、命中一选次数和一选命中率、进前四次数。训练页的本轮成绩下面直接能看到累计行，战绩页的「训练进度」里有汇总和三档明细。恢复默认设置不会清掉这些成绩。
- **表演赛速度会被记住**：上次选的慢速／中速／快速会存下来，下次打开表演赛还是那个速度；这个偏好也进了数据备份。

## 说明

- 「将军」的真人叫声还差一半：同一个来源里的将军音经同样方法核实是合成单音（转录无成词、频谱接近纯音），按既定口径没有采用；将军提示暂时保留合成双响，常驻搜寻继续。
- 顺带核实并跳过的还有 kongxiangchx/ChineseChess 的绝杀音（基频异常平稳、频谱偏纯音，判为合成），同样没有采用。
- 本版是正式签名版，可直接覆盖 1.5.0 及更早正式版升级，棋谱和设置都保留。
