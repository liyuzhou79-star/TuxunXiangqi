# 将！ v1.17.0 更新说明

这一版只做一件事，但它是复盘时每天都要用的：着法表从「只能看」变成「能点」。

## 新功能

- **复盘着法表点选跳步**：「全部着法」原来是一整段文字，找某一手只能靠拖滑杆慢慢对。现在每一手都是一张可点的着法片，按回合号排好（红黑一对一对），点哪一手，棋盘立刻跳到那一步之后的局面，页面还会自动滚回顶部棋盘处，不用再手动往上翻。当前停留的那一手会保持选中高亮，跳到哪儿了一眼清楚。

## 优化

- **标记跟着着法走**：整局分析标出的失误手（??）和疑问手（?）照样缀在对应着法后面，点选跳步和看标记互不耽误；跳步时如果正在自动播放，会先停下播放，不会刚跳过去又被播放带走。
- **滑杆与着法片双通道**：拖滑杆、长按前进后退、关键手巡览这些原有走法都保留，着法片是多加的一条直达通道，习惯哪种用哪种。

## 说明

- 本版是正式签名版，可直接覆盖 1.16.0 及更早正式版升级，棋谱和设置都保留。
- 着法片只是换了展示和跳转方式，棋谱数据、复盘的分析和试走功能都没有改动。
