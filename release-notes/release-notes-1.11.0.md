# 将！ v1.11.0 更新说明

这一版主攻复盘和残局两个地方：复盘时可以对单独一步做深度分析，残局解题时可以向引擎要一步提示；另外，将军的时候终于有真人喊声了。

## 新功能

- **复盘单步深度分析**：复盘页新增「深度分析这一步」——把当前这一步单独交给引擎深算约 2 秒，一次看前四个候选着法和各自的变化路线；实战里走的那一步排第几、比引擎一选丢了多少分，卡上都会写清楚。和「整局分析」共用一个引擎，两边不会同时跑；分析结果只在页面里看，不会改动棋谱文件。
- **残局「提示一步」**：解残局卡住时可以点「提示一步」，引擎用箭头指出当前的一选。每轮解题最多提示 3 次，提示用完按钮自动停用；用过提示解出的题目会在列表里如实标上「提示解出」，和独立解出的成绩分开记。
- **将军真人喊声**：将军时不再是电子提示音，换成真人喊的一嗓子「将军」。录音来自开源象棋项目 WatchChess（GPL-3.0 许可），收录前用语音转录和频谱分析核实过：转录结果明确是「将军」二字，音高有真人喊声自然的起伏，频谱带完整的谐波与共振峰结构，不是合成音。设置页的「资源与鸣谢」里已同步注明出处。

## 优化

- **引擎深算更快**：引擎启动时按手机处理器核心数开多线程搜索，并配上更大的哈希表。同样是深算 2 秒，现在能看得更深；日常对弈的出招速度和复盘分析都会受益。
- 复盘深析的结果卡在小屏上同样可以滚动查看，候选着法的记谱和变化不会挤在一起。

## 说明

- 本版是正式签名版，可直接覆盖 1.10.0 及更早正式版升级，棋谱和设置都保留。
- 「绝杀」的真人喊声（1.6.0 上线）不受影响；这版补上的是普通将军时的喊声，两段录音不是同一个来源，鸣谢文件里分别注明。
