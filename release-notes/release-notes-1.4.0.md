# 将！ v1.4.0 更新说明

这一版是整合审计版：把从规则、引擎、存档、备份到界面滚动的全部功能逐项回归自查了一遍（自查表记录在项目检查点里），并给复盘页补了两个一直缺的联动。

## 新功能

- **复盘页也有吃子展示了**：复盘时棋盘下方会按当前步显示双方各吃掉了什么、子力差多少——退到吃子之前，那颗子就从展示里消失，和对局页的口径完全一致（同一套推导逻辑，带一致性测试）。
- **走势图和当前步联动**：复盘的走势图上，你正在看的那一步会被圈出来，拖滑杆或步进时圈跟着走，形势曲线和棋盘局面不再各看各的。

## 审计与修复

- 全功能回归自查：规则引擎、记谱、FEN 解析、开局库（30 节点逐条对名）、残局与猜一选题面（32+ 题全验）、落点安危计算、吃子推导、棋谱导入导出、设置备份恢复（13 个设置键两边对齐）、引擎 UCI 冒烟、正式签名校验——逐项核对，本轮未发现新的功能性问题；全部页面确认可滚动到底，新加的棋力细调滑杆所在的设置面板同样在可滚动区域内。
- 吃子推导抽成了一套带快照参数的纯函数，对局页和复盘页共用，两个页面从此不会算出两套结果。
