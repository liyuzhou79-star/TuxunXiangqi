# 将！ v1.44.0 更新说明

残局题库扩充到六十五道。新增的四道全部先经过求解程序逐题验证、确认红方真胜才收录，延续题库「宁缺毋滥」的口径。

## 新增

- **第 62 题「马双兵胜士象全」**（马炮类，难度三星）：一匹马带双兵打士象全，子力单薄、全靠配合，求解程序证明藏着一串六步的连环杀，是本批最难的一道。
- **第 63 题「车炮双兵胜双士」**（车炮类，难度一星）：车炮带双兵，杀已成形，一步定局。
- **第 64 题「车双兵胜双士单象」**（车兵类，难度一星）：兵借车力压宫，子力差摆在那里，稳着走就能收官。
- **第 65 题「车马双炮胜双士单象」**（车马类，难度一星）：车马双炮火力全开，一步定局。

四道新题同样支持解题记录、提示、演示与「下一道未解的题」直达，也进入每日一题的轮换池。

## 说明

- 本批候选里另有两道经求解程序验证只是「优势明显」而非「必胜」的局面，按题库口径没有收录。
- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
