# 将！ v1.54.0 更新说明

开局库从 78 个定式节点扩充到 84 个，四条主线继续往深里走，最深的线路已经能陪你走完前十三手。

## 新增

- **顺炮线**：黑方进卒之后红方进兵、出车的续招入库；再往深一层，红方兵七进一之后黑方进卒的应法也补齐了。
- **顺炮·兵七进一线**：红方进兵之后黑方进卒、出车的应法入库。
- **飞相局线**：红方兵七进一之后黑方平车、出车、进卒的应法入库，飞相局最深线路推进到十三手。
- **仙人指路转中炮线**：红方兵三进一之后黑方进卒、飞象、出车的应法入库。
- **中炮对屏风马线**：红方马八进七之后黑方平车、进卒、出车的应法，以及红方炮八进二之后黑方飞象、进卒的应法入库。

新增节点全部经过本地校验程序逐手核对：每一步历史着法、每一条建议着法都合法，建议的中文记谱与记谱生成器逐字一致。

## 说明

- 猜一选的开局题池取材范围不变（仍取定式走了 4–6 手的局面），题量维持 20 道；这次加深的仍是 10 手以后的节点。
- 残局题库维持八十九道，全部经过求解程序审计。
- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
