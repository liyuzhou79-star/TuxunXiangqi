# 将！ v1.49.0 更新说明

残局题库扩充到七十七道。新增的四道全部先经过求解程序逐题验证、确认红方真胜才收录，延续题库「宁缺毋滥」的口径。

## 新增

- **第 74 题「双车双兵胜双士单象」**（双车类，难度一星）：双车带双兵，子力压倒，稳扎稳打收官。
- **第 75 题「双炮双兵胜双士」**（双炮双马类，难度二星）：兵当炮架、层层推进，三步之内见杀。
- **第 76 题「马炮三兵胜士象全」**（马炮类，难度二星）：三兵压境、步步推进，先破士象再收官。
- **第 77 题「车双炮双兵胜双士」**（车炮类，难度一星）：火力全开，两步之内见杀。

四道新题同样支持解题记录、提示、演示与「下一道未解的题」直达，也进入每日一题的轮换池。
