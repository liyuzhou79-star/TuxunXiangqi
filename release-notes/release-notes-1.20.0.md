# 将！ v1.20.0 更新说明

这一版继续打磨棋谱库和训练页：棋谱能按结果筛了，复盘页能直接把这局分享出去，残局页加了个不用挑题的入口。

## 新功能

- **棋谱按结果筛选**：棋谱页在模式筛选下面多了一排结果筛选——全部结果、红方胜、黑方胜、和棋、未分胜负。想回看自己赢过的局、或者专找和棋研究，不用再一页页翻；和模式、搜索词可以叠加使用，多选管理里的「当前列表」也跟着筛选走。
- **复盘页直接分享这局**：复盘页标题下面加了「复制这局」和「分享这局」。以前想把一局发给朋友，得退回棋谱库找到那局再操作；现在看着复盘就能发，整局分析算出的失误标记也会一并带上。
- **残局随手来一题**：残局页加了「随手来一题（优先未解）」按钮，从当前筛选出的题目里随机抽一题、优先抽还没解出的。不想挑题的时候点一下就开练；配合难度筛选，就是随机一道这个难度的未解题。

## 说明

- 本版是正式签名版，可直接覆盖 1.19.0 及更早正式版升级，棋谱和设置都保留。
- 棋谱的结果筛选按保存时记录的结果文字区分；中途存下的未完局会归在「未分胜负」里。
