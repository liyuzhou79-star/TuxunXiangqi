# 将！ v1.29.0 更新说明

这一版把开局库往下多走了几步棋：最常见的几条定式线各加深一层，战绩页也能看到每日一题的累计天数了。

## 改进

- **开局库从 30 个节点扩到 36 个**：四条最常见的线各往下走了一层——中炮对屏风马（进三卒、横车两条变例，以及屏风马双马齐出后的局面）、顺炮（红方双马齐出后黑方的应法）、仙人指路对兵局（红方亮出中炮后黑方的应法）、飞相局（黑方屏风马成形后红方的走法）。每个新节点的建议着法都经过规则与记谱的自动校验，对局页和开局库浏览页都会在这些更深的位置继续给出定式建议。
- **战绩页补上每日一题天数**：训练进度卡里新增一行——每日一题累计完成多少天、当前连续多少天，和首页卡上的数字同源。

## 说明

- 顺手把功能介绍里两个过时的数字订正了（开局库节点数、猜一选题量），与当前版本一致。
- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
