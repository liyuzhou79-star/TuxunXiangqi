# 将！ v1.80.0 更新说明

开局库扩充到一百六十四个定式节点；棋谱导入加了一道合法性门栏。

## 新增

- **开局库第十九轮扩充**：在一百五十八个节点的基础上再添六个，来到一百六十四个，最深二十五手。顺炮等主线继续向后延伸，照库开局能陪你走得更远。

## 修复

- **坏棋谱也能导入棋谱库**：此前粘贴导入只看 FEN 一栏是不是空的——内容写错的 FEN 照样进库，打开复盘时局面会被悄悄换成标准开局，着法走到一半走不下去还照样显示全部步数。本版在导入口加了校验：FEN 必须能解析、双方将帅齐全，否则整条拒绝；着法只保留能实际走出来的部分，存进库的棋谱和复盘能看到的完全一致。从本应用导出的棋谱不受影响，照常完整导入。

## 说明

- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
