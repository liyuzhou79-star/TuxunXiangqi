# 将！ v1.38.1 更新说明（急修）

这一版专修落点安危标记：有用户实测发现，残局页里能落的地方全是红点、能安全吃掉的子身上又看不到绿圈。这次把「判定 → 标记」整条链逐行审了一遍，修了三处。

## 修复

- **残局页补上安危判定**：安危标记（绿点＝安全、红点＝送死、绿圈＝吃完安全、无标记＝吃完被反吃）此前只接在了对局页，残局页漏接，于是所有落点都只剩「未判定」的兜底标记。本版残局页与对局页共用同一套判定入口和同一个设置开关，表现完全一致。
- **没有判定时不再标红**：兜底的普通落点标记此前借用了棋子红墨色，看起来和「送死红点」几乎一样，这是「全盘皆红」的直接来源。现改为中性墨色：没判定就只是提示能落，绝不冒充危险。
- **吃子绿圈改画在棋子之上**：绿圈此前画在棋子下层，自从棋子换成成品图贴图后，圈的下半截被棋子的侧壁和阴影盖住，实际看不见。本版把吃子圈移到棋子画完之后再画，整圈完整可见；落子白光晕、将军脉冲的画法不受影响。

## 说明

- 判定本身（哪步安全、哪步送死）经复核没有算反：新增回归测试把炮隔子反吃、兵卒过河前后攻击范围、四种标准情形（安全步／送死步／安全吃／被反吃）与整条「判定→标记」映射逐项钉死。
- 猜一选页在公布答案前仍不给安危颜色（避免泄题），但落点标记同样改走中性墨色，不再发红。
- 对局棋力参数（档位、细调、思考时间与深度）保持现状，没有任何改动。
