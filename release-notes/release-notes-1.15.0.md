# 将！ v1.15.0 更新说明

这一版给开局库开了一扇正门：以前它只在对局分析时露一脸，现在首页有了专门的浏览页，定式能搜、能看、能在棋盘上摆出来研究；战绩页的残局分类统计也从文字升级成了进度条。

## 新功能

- **开局库浏览页**：首页新增「开局库」入口。内置的 30 个定式节点、80 余条建议着法全部列出来，每条线写清走到这个局面的记谱和这里的建议着法。点任意一条线，页面上方的棋盘立刻摆出那个局面，建议着法用箭头标出；同一局面的几条建议可以逐个点着切换箭头对比。只看不动，不会误开一局。
- **开局库搜索**：搜索框既能按定式名找——「中炮」「顺炮」「仙人指路」「飞相」都行；也能按着法记谱找——输入「马二进三」「炮二平五」，历史上走过这步的线、以及建议里包含这步的线都会出来。搜不到时有明确提示，不会白屏。

## 优化

- **战绩页残局统计有了进度条**：六个残局分类（双车、车马、车炮、车兵、马炮、双炮双马）原来只有「已解 X / Y 题」的文字，现在每类下面多了一根完成进度条，解到哪儿了扫一眼就知道，和文字数字完全同源，不会两套说法。

## 说明

- 本版是正式签名版，可直接覆盖 1.14.0 及更早正式版升级，棋谱和设置都保留。
- 开局库的内容和对局分析面板引用的是同一套内置数据，这次只是把它完整开放出来浏览，没有增删定式本身。
