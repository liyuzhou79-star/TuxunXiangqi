# 将！ v1.38.0 更新说明

这一版补的是练题的连贯性：解完一道残局不用再退回列表翻下一道，复盘的深析小图也和棋盘对上了步。

## 改进

- **残局解题页「下一道未解的题」**：解题页按钮区新增直达按钮，点一下就跳到下一道还没解出的题——优先同分类里往下顺延，同类都解完再去别的分类找，全解完时按钮自动隐藏。卡住的题也可以用它先跳过，回头再战。跳转时上一题的步数、提示次数、已解状态不会串到新题里。
- **深析评分差小图当前步高亮**：复盘页 1.36.0 加的深析评分差小图，现在会给「棋盘上正在看的这一步」对应的柱子描一圈（和上方形势走势图的高亮同一套语言），图和棋盘翻到哪一步对得上。
