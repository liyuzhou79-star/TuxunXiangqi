# 将！

免费开源的中国象棋 App，基于 Pikafish 引擎。

## 简介

「将！」是一款完全免费、开源的象棋应用，全部功能都在手机本地运行：

- **强力引擎对弈**：内置 Pikafish（开源象棋引擎，GPL-3.0），三档棋力，还可以让它一马、双马甚至车马炮；全部计算在本地完成，不联网、不上传棋局
- **AI 表演赛**：两台引擎自弈对打，可暂停、可调速，适合观摩高手过招
- **多候选分析**：一键给出前四个候选着法、各自的形势判断（胜率与优势）和后续变化，点哪个就在棋盘上标哪个；开局阶段还会给出内置开局库（18 个定式节点）的走法建议
- **局内走势**：对局中自动记录每一手的形势分数，连成曲线，哪几手翻盘一目了然
- **摆棋编辑**：自己摆任意局面（残局、名局、卡住的棋），从那里开始对弈或分析
- **棋钟与礼仪**：可选棋钟（超时判负）、认输、求和（引擎只在不占优时同意）、悔棋
- **棋谱库与复盘**：对局结束自动存谱，可搜索、筛选、改名；复盘能逐步回放、长按连跳、自动播放，还有每手形势、走势图、关键手巡览和「和引擎一选对比」
- **导入导出**：棋谱可导出为文本或文件，也能粘贴/选文件导回来，换手机不丢棋
- **局面图分享**：对局中一键把当前局面截成图发给朋友
- **猜一选训练**：看局面猜引擎的第一选择，三档难度，还能从你自己的棋谱里出题；猜错的自动进错题本，随时重练；还有 30 秒限时挑战模式
- **残局题**：二十四道「红先胜」经典残局（含每日一题，首页有今日一题卡片），你执红、引擎执黑防守兼当裁判，哪步把优势走没了当场提醒，还有正解演示；每道题会记下你最快解出的步数，方便反复挑战自己
- **音效**：落子、吃子、将军、胜负都有短音效，全部由程序现场合成，不带任何音频文件，设置里可以关掉
- **新手指南**：每种棋子一张小棋盘图，能走的格子都标好了，再讲清将军、将死、困毙和中文记谱
- **设置与战绩**：浅色／深色／跟随系统主题、默认难度与棋钟、个人战绩（对引擎各档胜负、赢过的最高难度、训练进度）
- **数据备份**：棋谱、错题本和设置一键导出为文件或文本，换手机粘贴回来即可恢复；引擎在启动时预热，第一次开局不用等
- **检查更新**：设置里手动点一下才联网查新版本，平时完全不联网
- **干净清爽**：没有广告，没有账号，没有内购

界面采用 Google Material 3 设计，棋盘是木质棋盘与圆片棋子的经典样子。

> 当前版本 0.9.0。这一版主打体验：新增程序合成音效（落子、吃子、将军、胜负），残局题扩充到二十四道，开局库定式节点翻倍，猜一选加了限时挑战。

## 构建

调试包由 GitHub Actions 的 Build Debug 工作流构建。Pikafish 引擎二进制在 CI 中使用 Android NDK 编译（arm64-v8a），NNUE 网络文件为 Pikafish 官方默认网络（pikafish.nnue，随安装包内置，装完就能用）。
