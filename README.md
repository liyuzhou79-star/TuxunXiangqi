# 将！

免费开源的中国象棋 App，基于 Pikafish 引擎。

## 简介

「将！」是一款完全免费、开源的象棋应用，全部功能都在手机本地运行：

- **强力引擎对弈**：内置 Pikafish（开源象棋引擎，GPL-3.0），三档棋力加 1–10 棋力细调，还可以让它一马、双马甚至车马炮；全部计算在本地完成，不联网、不上传棋局
- **AI 表演赛**：两台引擎自弈对打，可暂停、可调速，适合观摩高手过招
- **多候选分析**：一键给出前四个候选着法、各自的形势判断（胜率与优势）和后续变化，点哪个就在棋盘上标哪个；每个候选还能「试走这条线」——把引擎的变化一步步摆到棋盘上慢慢看（只是预览，不会真的落子，正式走子自动退出）；开局阶段还会给出内置开局库（404 个定式节点）的走法建议
- **局内走势**：对局中自动记录每一手的形势分数，连成曲线，哪几手翻盘一目了然
- **摆棋编辑**：自己摆任意局面（残局、名局、卡住的棋），从那里开始对弈或分析
- **落点安危提示**：选中棋子，落点立刻分安危——绿点安全、红点送死，能吃的子绿圈表示吃完安全、没标记表示会被反吃；本地规则即时判断，设置里可关
- **吃子展示**：棋盘下方列出双方已吃掉的子和子力优劣；将军时被将的将/帅有红色脉冲环提醒
- **棋钟与礼仪**：可选棋钟（超时判负、最后 10 秒每秒滴答提醒）、认输、求和（引擎只在不占优时同意）、悔棋
- **棋谱库与复盘**：对局结束自动存谱，可搜索、筛选、改名；复盘能逐步回放、长按连跳、自动播放，还有每手形势、双方吃子展示、走势图（当前步在图上有圈标记）、关键手巡览、「和引擎一选对比」，以及整局分析（引擎逐手评分、自动标出疑问手与失误手并存回棋谱）
- **导入导出**：棋谱可导出为文本或文件，也能粘贴/选文件导回来，换手机不丢棋
- **局面图分享**：对局中一键把当前局面截成图发给朋友
- **猜一选训练**：看局面猜引擎的第一选择，三档难度每档 12 道题，还能从你自己的棋谱里出题；猜错的自动进错题本，随时重练；还有 30 秒限时挑战模式（成绩单独统计、不与普通模式混记）；答题成绩会累计统计（总答题数、一选命中率、进前四次数），在训练页和战绩页都能看到
- **残局题**：二百八十三道「红先胜」经典残局，按双车／车马／车炮／车兵／马炮／双炮双马六类分组、每道标了难度星级（含每日一题，首页有今日一题卡片），你执红、引擎执黑防守兼当裁判，哪步把优势走没了当场提醒，还有正解演示；每道题会记下你最快解出的步数，方便反复挑战自己
- **音效**：落子、吃子、胜负用真实录音（开源项目 ChessRoad，GPL-3.0），将军时有真人「将军」喊声（开源项目 WatchChess，GPL-3.0），将死／困毙终局有真人「绝杀」喊声（开源项目 chinese-chess-fish，MIT），设置里可以关掉；棋子字为莫大毛筆體开源书法字，棋盘用真实胡桃木纹理，出处见 THIRD_PARTY_NOTICES.md
- **新手指南**：每种棋子一张小棋盘图，能走的格子都标好了，再讲清将军、将死、困毙和中文记谱
- **设置与战绩**：浅色／深色／跟随系统主题、默认难度与棋钟、一键恢复默认设置、个人战绩（对引擎各档胜负、赢过的最高难度、训练进度）
- **数据备份**：棋谱、错题本和设置一键导出为文件或文本，换手机粘贴回来即可恢复；引擎在启动时预热，第一次开局不用等
- **检查更新**：设置里手动点一下才联网查新版本，平时完全不联网
- **干净清爽**：没有广告，没有账号，没有内购

界面采用 Google Material 3 设计，棋盘是木质棋盘与圆片棋子的经典样子。

> 当前版本 1.175.0（正式版）。残局题库 331 题，开局库扩充到 446 个定式节点（最深 72 手）。正式签名发布。各版本更新说明见 [release-notes](release-notes/) 文件夹。

## 构建

调试包由 GitHub Actions 的 Build Debug 工作流构建，正式包由 Build Release 工作流构建（正式签名，构建时校验签名证书指纹，不符不予出包）。Pikafish 引擎二进制在 CI 中使用 Android NDK 编译（arm64-v8a），NNUE 网络文件为 Pikafish 官方默认网络（pikafish.nnue，随安装包内置，装完就能用）。
